# 小六壬占（网页版 · 可打包 APK）

六宫掌诀占卜小工具，纯本地运行（无任何外部依赖，**断网可用**）。

## 快速开始

```bash
cd suangua-app
node server.js
```

然后：
- **电脑上**：浏览器打开 http://localhost:8080
- **手机上**：手机与电脑连同一 WiFi，浏览器打开 http://电脑IP:8080（电脑 IP 用 `ipconfig` 查看）

## 功能

| 功能 | 说明 |
|---|---|
| 掌诀版本 | 首页可选 **六宫 / 九宫**：六宫用真实左手照片；九宫用参考掌诀图（左手掌心面，三指三节布局）+ 病符、桃花、天德三宫，数数顺序 大安1留连2速喜3赤口4小吉5空亡6病符7桃花8天德9 |
| 所问何事 | 起卦前先选所问（求财/婚恋/事业/学业/健康/出行/寻物/官司/家宅等），解卦自动结合六亲用神 |
| 时间起卦 | 自动取当天日期并转农历，按 月→日→时 三课起卦（用户未手动改日期则每次自动刷新为今天） |
| 报数字起卦 | 1-3 个数字连续数数：第一数从大安数，第二数以第一数落宫为一接着数，第三数以第二数落宫为一接着数 |
| 写字起卦 | 按汉字笔画起卦（内置常用字笔画表，未收录可换字或改报数字），数数规则同上 |
| 掐指动画 | 真实左手照片（六宫/九宫穴位已对准），墨点游走点穴（五行流转）+ 外圈八卦环运转（掐指加速、落定缓转），穴位名只在掐到/落宫时显示，可"跳过掐指" |
| 解卦内容 | 三宫吉凶 + 五行/六神/地支 + 掌诀断语 + 六神临宫总断 + 应期 + 六亲用神参考 |

## 内容体系

五行/六神采纳邵一尘体系：大安木·青龙 / 留连土·螣蛇 / 速喜火·朱雀 / 赤口金·白虎 / 小吉水·玄武 / 空亡土·勾陈。六宫、九宫两套体系勿混用（见 docs 底本说明）。

## 打包 APK（后续）

需要 JDK 17+ 与 Android SDK（安装 Android Studio 即可），装好后可用 Capacitor 打包：
```bash
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init 小六壬占 com.example.xiaoliuren --web-dir=.
npx cap add android
npx cap sync
npx cap open android   # Android Studio 中 Build APK
```
