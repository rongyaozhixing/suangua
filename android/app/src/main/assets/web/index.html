使用说明

一、怎么起卦（四步）

  1. 选所问：想好要问什么事（求财/婚恋/事业/学业/健康/出行/寻物/官司/家宅/其他）
  2. 选版本：六宫（常用，正统）或九宫（进阶，含桃花/病符/天德三宫）
  3. 选方式：时间起卦（取当下时辰，古法正统）/ 报数字（随口报 1-3 个数）/ 写字（用汉字笔画数）/ 灵机（见物闻声即时取数）
  4. 看掐指：拇指沿手掌穴位逐宫数数，落宫即卦象

二、怎么读结果

• 开头（月宫）→事情开端；过程（日宫）→发展经过；结果（时宫）→最终走向，以结果宫为主。

• 总断：开头三宫吉凶给一句话结论。

• 宫位卡：每宫的性格、五行、六神、应期（多久有结果）、细节断语，点开可看。

• 用神/六亲参考：按你所问分类给建议。

• 进阶断语：六神临六亲 36 条细断，供深入学习。

三、六宫穴位（左手）

食指根=大安（吉）· 食指尖=留连（凶）· 中指尖=速喜（吉）· 无名指尖=赤口（凶）· 无名指根=小吉（吉）· 中指根=空亡（凶）。顺数顺序：大安→留连→速喜→赤口→小吉→空亡循环。

四、九宫（进阶）

九宫=六宫加桃花（姻缘人缘）、病符（健康灾病）、天德（贵人天助）三宫。布局：食指=留连/大安/桃花，中指=速喜/空亡/小吉，无名指=病符/赤口/天德。

五、命盘排盘

输入出生公历日期+时辰+性别，排出本命盘（地支/五行/六亲/六神/五星）、大运（每十年一宫）、流年与流月，供看一生运势参考。
